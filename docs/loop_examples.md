# v3 / v4：课堂任务、独立验算与历史录制

本轮主讲中，v3 计算复杂表达式，v4 核算采购付款。它们是不同任务，不能作为同题或严格单变量性能比较。两版的生成上限也不同（500 与 1600 token）。新题只做了本地独立验算，没有请求模型 API，也没有新增或改写录制。

分别启动 `python agent_v3.py`、`python agent_v4.py`，在 `$ ` 后输入题目。支持 bracketed paste 的终端可整段粘贴，按一次 Enter 提交；Ctrl+D 或 Ctrl+C 结束。

两版都直接用 `eval(expression)` 计算，乘方写 `**`；均固定请求 `deepseek-flash`、关闭 thinking、不传 temperature。v3 处理首个响应中的一轮工具请求，该轮可以有多个调用；回填后不带 tools 再请求一次回答。v4 每次回填后仍带 tools 请求，直到模型不再请求工具。

## 当前 v3 提示词：复杂表达式

```text
计算((12345 * 6789 - 9876 * 5432) / 3 + 2468 * 1357) * 7 - 1233
```

| 独立核对步骤 | 结果 |
|---|---:|
| 12345 × 6789 | 83810205 |
| 9876 × 5432 | 53646432 |
| 两者相减再除以 3 | 10054591 |
| 2468 × 1357 | 3349076 |
| 相加、乘 7，再减 1233 | **93824436** |

基准使用有理数运算独立复核；现有 calculator 用 Python `/` 可能显示 `93824436.0`，数值相同。本题可由一次工具调用完成，不用于制造 v3 失败。课堂只看工具请求、实际执行和结果回填的分工。

## 当前 v4 提示词：采购付款核算

```text
采购367件单价129.80元的材料、284件单价87.60元的材料，以及159件单价216.40元的材料。
商家规则：原价满10万元打九三折，否则打九七折；折扣后再减1280.45元优惠券。优惠后的商品金额不足10万元，另收385.60元运费，否则免运费。商品金额另加13%的税，运费不计税。
请核算最终付款金额，保留两位小数，并说明实际触发了哪些优惠和运费规则。
```

本地使用十进制定点数核算，按题目“商品金额”指折扣和优惠券后的商品金额，运费不计税；中间值保留精度，最终金额四舍五入到两位小数。

| 项目 | 未提前舍入的金额（元） | 触发的规则 |
|---|---:|---|
| 367 × 129.80 | 47636.60 | 第一类材料 |
| 284 × 87.60 | 24878.40 | 第二类材料 |
| 159 × 216.40 | 34407.60 | 第三类材料 |
| 原价合计 | 106922.60 | 满 10 万元，九三折 |
| 九三折后 | 99438.0180 | 不采用九七折 |
| 再减 1280.45 元优惠券 | 98157.5680 | 券后不足 10 万元 |
| 运费 | 385.60 | 券后不足 10 万元，收运费 |
| 商品税额：98157.5680 × 13% | 12760.483840 | 运费不计税 |
| 商品 + 税 + 运费 | 111303.651840 | 最终付款 **111303.65** |

若逐项先保留到分：九三折商品 99438.02 元、券后 98157.57 元、税 12760.48 元，最终同为 111303.65 元。课堂应同时核对金额与规则：**九三折、减券、收费运费、仅商品计税**。

此任务可以分多次调用，也可能被模型合为一次计算。循环提供再次请求工具的能力，不强制调用次数，不保证模型每次正确选择规则或得到正确金额。按实际 Tool Result 和答案判读；解释中的函数名或“接下来计算”不算执行证据。

```text

每次只请求当前一步的计算，必须等工具返回后再进行下一步，不要把整条流程合成一个表达式。
```

|---|---:|
| A = 123456789 × 987654321 | 121932631112635269 |
| B = A 的末六位 | 635269 |

### 历史证据与判读

两份录制来自北京时间 2026-10-15 23:24 的真实彩排。v3 两题各只实际执行第一步，随后把下一次调用写成带 DSML 标记的正文，没有终值；v4 分别实际执行两次、三次 calculator，得到上述标准答案。两版均关闭 thinking。这些观察只对应已录制的输入，不保证未来运行重复。

录制保存真实输入、UTC 时间、原始终端输出和源码 SHA，网页只回放，不执行正文里的调用。再次运行以下命令仍彩排历史题面，输出到新目录：

```bash
rehearsal_dir=$(mktemp -d)
python verify_live.py --stage v3 --stage v4 --output-dir "$rehearsal_dir"
```

对历史逐步任务，终值正确但跳过指定工具步骤，应区分为数值正确、过程未满足；没有终值是未完成，不能说它给出了错误数值。对当前新题，题目没有要求固定调用次数，合并表达式本身不构成失败。
