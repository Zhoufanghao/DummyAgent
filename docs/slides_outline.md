# teach：16 页课程大纲

课程：《从文字接龙到 AI Agent：用一个 API 构建智能体》  
时长：45 分钟，16 页，与 [Slidev 源文件](../slides/slides.md) 的页序和时段对应。源码细节在 Terminal 展示，幻灯片聚焦从生成、上下文、工具到反馈循环的原理。

所有 SDK 调用直接使用 `model="deepseek-flash"`。别名的既往核查日期与公开模板来源见 [sources.md](sources.md)，不把旧核查当作今天的重新核验。第 7 页展示公开 DeepSeek-V3 模板，不代表当前托管 API 的内部模板。

六份独立文件 `agent_v0.py`—`agent_v5.py` 位于项目根目录。输入提示为 `$ `；支持 bracketed paste 的终端中，多行粘贴保留换行，按一次 Enter 提交；空白输入跳过，Ctrl+D 或 Ctrl+C 结束。每页只承载一个主问题，完整源码和相邻差异交给 Terminal 或教学网页。

第 8 页 v3、第 10 页 v4 在普通 HTML 放映页显示完整提示词及“复制提示词”按钮；第 12 页 v5 提供空白任务输入区，现场编辑并复制，第 13 页继续验收。第 3—7 页不显示可执行提示词或复制区，只呈现原理、角色和模板占位示意；v0—v2 的终端输入保留在 [课堂演示提示词](../slides/课堂演示提示词.md) 和 [教师讲稿](teacher_script.md) 中。

## 第 8 页：v3 提示词

以下原文直接显示在普通 HTML 放映页，并提供“复制提示词”按钮。

```text
计算((12345 * 6789 - 9876 * 5432) / 3 + 2468 * 1357) * 7 - 1233
```

本地独立验算结果为 **93824436**；calculator 可能输出 `93824436.0`，数值相同。本题可一次工具调用完成，不要求反馈后多步执行。

## 第 10 页：v4 提示词

以下三行原文直接显示在普通 HTML 放映页，并提供“复制提示词”按钮，整段复制后作为一次终端输入。

```text
采购367件单价129.80元的材料、284件单价87.60元的材料，以及159件单价216.40元的材料。
商家规则：原价满10万元打九三折，否则打九七折；折扣后再减1280.45元优惠券。优惠后的商品金额不足10万元，另收385.60元运费，否则免运费。商品金额另加13%的税，运费不计税。
请核算最终付款金额，保留两位小数，并说明实际触发了哪些优惠和运费规则。
```

本地独立验算：原价 106922.60 元，九三折后 99438.0180 元，券后商品 98157.5680 元；不足 10 万元收运费 385.60 元；券后商品税 12760.483840 元，运费不计税；最终 **111303.65 元**。完整步骤见 [任务与验算](loop_examples.md)。

新 v3/v4 是不同任务，不作严格性能比较。采购题也可能合为一次计算，v4 不保证多次调用或成功。上述基准来自本地有理数和十进制运算，**没有新增模型实测**。

## 第 12—13 页：v5 自由发挥

第 12 页提供空白任务输入区和“复制提示词”按钮，不预设提示词、温度数据或输出文件名。教师现场确定任务和验收标准，编辑任务后复制到终端；第 13 页核验模型实际请求了什么，程序实际执行了什么，最终结果能否独立核对。若任务涉及文件，按实际路径重新打开检查。工具报错时，按真实反馈讲后续调整；一次成功时不编造失败。

## 备课与历史证据

在已加载 `DEEPSEEK_API_KEY` 的 Python 环境中安装依赖后运行：

```bash
python -m pip install -r requirements-lock.txt
python preflight.py
python chat_template_demo.py
python build_viewer.py
```

`preflight.py` 离线核对语法、独立性与录制来源，不请求 API。现有 `recordings/` 及 `verify_live.py` 仍采用历史 v3/v4 同题与 v5 温度任务，**不对应当前新题**。回放时明确标为历史案例，不把旧结果当新题结果。历史题和标准答案见 [循环案例](loop_examples.md)，温度备用任务见 [Bash 说明](bash.md)。

如再次运行 `verify_live.py`，用新的 `--output-dir` 保留旧录制；脚本仍请求历史题目。覆盖需显式 `--overwrite`，再预检、构建。教师脚本临时执行目录结束后删除，REPLAY 不恢复文件。详见 [教师讲稿](teacher_script.md) 与 [验证记录](../VALIDATION.md)。

## 配置与输出约定

六阶段依次为独立续写、文本 history、messages、一次工具请求与回填、持续反馈循环、Bash 执行。六版非流式，SDK 超时 45 秒、重试 1 次。所有阶段使用 API 默认采样设置，不传 temperature；v2—v4 固定关闭 thinking。v5 顶部 THINKING 控制模式与 reasoning_content 显示，8192 token 由思考与回答共用，实际执行仍看 Tool Result。

LIVE、REPLAY、教学示意与本地独立验算必须明确区分。思考文本、函数名、DSML 标记和“已完成”的文字都不能代替工具结果或内容核验。第 14—15 页仅使用有日期的历史材料，不延伸为当前产品套餐、默认设置或可靠性主张。
